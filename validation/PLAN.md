# Multica HarmonyOS 功能验收计划

只操作本轮新建的验收数据；不邀请成员、不修改真实项目、不对外发通知、不更换凭据、不发布代码。最小 agent 任务允许实际模型调用；记录配额或登录失败，不绕过权限。

| 类别 | 验证方法 |
| --- | --- |
| 登录/重启 | 当前会话读取、桌面重启保留、外部 daemon 独立存活 |
| Agent | 8 runtime 在线、逐个最小任务→回复→完成；取消/重试 |
| 项目/任务 | 专用项目、任务 CRUD（仅删本轮数据）、状态、优先级、子任务、搜索 |
| 协作 | 评论创建/读取/更新、标签、订阅、附件 |
| 组织 | 专用 squad、工作流、属性、视图的创建与读取（不修改默认项） |
| 自动化 | 专用一次性手动 automation，不启用长期计划或公网 webhook |
| 桌面 | 导航、聊天、搜索、模型选择、目录选择、窗口及设置 |
| 平台能力 | 深链、通知/权限、剪贴板、更新机制、daemon 恢复 |

结果分 PASS / FAIL / BLOCKED / NOT_TESTED；API 结果不冒充桌面端操作结果，online 不冒充模型可用。付费/外部集成、OS 权限未授予、账户额度不足等单列；不能把有限抽样宣称为所有功能通过。
